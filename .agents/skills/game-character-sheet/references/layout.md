# 여백과 얼굴 크기

제작 시트에서 머리카락이 안전하게 들어갈 공간과 게임에서 얼굴이 크게 보이는 정도는 별개다. 여백을 먼저 확보한 다음 최종 런타임 셀의 눈/턱 좌표로 게임 배율을 맞춘다. 남녀 구분에 따른 배율이나 머리 길이에 따른 배율을 두지 않는다.

## 제작 시트 여백

- 셀 512×960 기준 생성 목표: 양옆 각각 80px 이상, 위아래 각각 64px 이상. 머리카락·귀·눈물까지 포함한 폭은 최대 352px이다.
- 정규화 후 통과 하한: 양옆 각각 64px, 위아래 각각 32px. `prepare_sheet.py`가 셀별 실제 값을 기록하고 부족하면 실패한다.
- 기본 포장 명령에 `--pad-to-margin`을 붙인다. 온전한 5개 셀의 최대 돌출 범위를 측정해 고정 셀 중심 주위에서 공통 배율·패딩으로 목표 여백을 만든다. 원본 경계 접촉이 있으면 보정을 실행하지 않고 실패한다. 순수 간격 부족은 이미지 재생성 대신 이 포맷 정리로 해결한다.
- 최종 목표를 QA의 실제 픽셀 값으로 확인한다: 양옆 각각80px, 위아래 각각64px, 인접 간격160px 이상. 정규화 후 하한과 생성 목표를 혼동하지 않는다.
- alpha ≥16은 보이는 내용 경계 측정에만 쓴다. 실제 이미지 alpha를 임계값으로 지우지 않는다.
- 머리가 겹치거나 잘렸으면 먼저 image_gen으로 복원·레이아웃 수정한다. 크롭으로 잘린 머리를 숨기지 않는다. 5개 표정은 같은 배율로 축소한다.
- 출력 폭이 5로 나누어떨어지지 않으면 전체 셀에 공통 배율/패딩으로 제작 규격을 맞춘다. 정규화가 여백 부족·클리핑을 자동 해결했다고 간주하지 않는다.

## 게임에서 눈/턱 기준으로 맞추기

1. 런타임 크롭/패딩을 확정한다. 정사각형 셀로 바꾸는 경우에도 5개 표정에 같은 변환을 적용하고 보이는 머리·눈물이 잘리지 않는지 확인한다.
2. 승인된 기준 캐릭터(현재 수지)와 새 캐릭터의 **최종 런타임 neutral 셀**에서 왼쪽/오른쪽 눈 중심, 피부 턱끝 좌표를 직접 확인한다. 눈물·머리카락 끝을 턱으로 측정하지 않는다. 눈이 기울어졌으면 두 눈 y 평균을 눈 중심선으로 쓴다.
3. 주요 크기 기준은 `D = chin.y − mean(eyes.y)`이다. 양쪽 눈 중심 거리 P는 보조 검토 기준이다. 눈의 개안 정도나 안구 그림의 높이는 표정에 따라 달라지므로 크기 기준으로 쓰지 않는다.
4. 기준 캐릭터가 렌더링되는 눈–턱 거리에 새 캐릭터 D를 맞추는 **균일 배율 하나**를 계산한다. 같은 캐릭터의 표정 5개에 모두 적용한다. 눈–턱 거리와 눈 간격을 둘 다 강제로 같게 하려고 가로/세로를 따로 늘리지 않는다. P 차이는 얼굴형 특성일 수 있다.
5. 기준 캐릭터와 턱끝 높이 및 눈 midpoint 가로 위치를 맞춘다. 머리카락은 더 높거나 넓어도 괜찮다. 피부 얼굴 크기가 비슷한지 실제 렌더러에서 나란히 확인한다. 안경은 새 눈 중심선, 모자·리본·핀은 각 머리카락 위치로 조정한다.

`fit_face.py`는 수동 좌표로 계산만 한다. 좌표 입력은 아래 형태이며 단위는 **최종 셀 픽셀**, 각 셀의 왼쪽 위가 (0,0)이다. 실제 측정값으로 채운다.

```json
{
  "frame": [512, 512],
  "left_eye": [170, 290],
  "right_eye": [290, 290],
  "chin": [230, 430]
}
```

기준 캐릭터 JSON에는 현재 렌더러의 기준 좌표 값도 넣는다. 아래 숫자는 **형식 설명용**이며 수지의 측정값이라고 간주하지 않는다. `faceX_px`는 250px rig 상자 안의 faceX 위치(50%이면 125)다.

```json
{
  "frame": [512, 512],
  "left_eye": [170, 290],
  "right_eye": [290, 290],
  "chin": [230, 430],
  "rig": {"faceW": 300, "faceH": 300, "faceY": -56, "faceX_px": 125, "boxW": 250}
}
```

```sh
python scripts/fit_face.py --landmarks /absolute/path/new-neutral-landmarks.json \
  --reference /absolute/path/approved-reference-landmarks.json \
  --output /absolute/path/face-fit.json
```

출력의 `rig_candidate`는 자동 적용하지 않고 리뷰한다. `eye_center_y`가 렌즈 중심 높이다. 현재 안경 공식에 넣을 `glassesY = eye_center_y − 0.53 × glassesW / 2`이며, glassesScale 및 아이템별 lensY 보정은 기존 렌더러가 처리한다. 눈 간격 차이가 10%를 넘으면 경고를 내지만, 실제 얼굴형을 보고 판단한다.

크기 계산 후 얼굴이 rig 상자 밖으로 돌출해도 즉시 머리 전체를 축소하지 않는다. 화면의 overflow·모자 잘림을 확인하고 배치/공통 패딩을 조정한다. 얼굴 크기를 다시 정해야 한다면 눈–턱 기준을 유지하며 실제 비교 결과를 기록한다.
