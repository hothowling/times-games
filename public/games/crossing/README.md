# 구구단 건너기 / Quiz Crossroads

세로 화면에서 차량과 바위·나무를 피해 정답 횡단보도를 건너는 무한 진행 게임.

- 하트 3개로 시작한다. 오답 또는 차량 충돌마다 하트 1개가 줄고, 0개가 되는 순간 종료·기록 저장한다. 정해진 결승선이나 통과 개수 제한은 없다.
- 구간이 이어질 때마다 새 문제·바위·나무·선물상자를 생성한다. 최고 점수·거리·플레이 횟수를 저장하고 공통 기록·랭킹·Sparkles 보상에 연결한다.
- 2차선 일반 도로 사이에 3차선·4차선의 넓은 도로가 섞인다. 각 차선의 속도가 다르며, 3구간마다 난이도가 오른다. 차량 속도는 기본의 최대 2.2배, 차량 수는 차선당 최대 3대까지 증가한다. 보도에서는 시간 제한 없이 기다릴 수 있다.
- 차량은 부드럽게 가속·감속하며 넓은 도로의 흐름이 조금 더 빠르다. 택시·스쿠터는 짧고 경쾌하게, 버스·트럭은 묵직하게 속도가 변한다. 개별 가속 변위를 제한해 장시간 플레이해도 같은 차선의 차량 간격이 유지된다. 이동 거리와 현재 속도를 함께 계산해 충돌 판정과 표시가 일치하고 속도 변화나 감속 아이템 해제 시 위치가 튀지 않는다.
- 퀴즈 건널목은 일반 도로 폭과 관계없이 두 번 전진하면 통과한다. 입구에서 정답 길로 한 칸, 맞은편 안전지대로 한 칸 이동한다. 표지판은 낮게 배치하며 펜스·기둥은 없다.
- 첫 세 문제는 구구단이며, 이후 수도 퀴즈와 구구단이 번갈아 나온다. 구구단은 2~9단 × 1~9의 72개 조합을 섞어서 순환한다. 진행할수록 수도 문제의 국가 범위도 넓어진다.
- 선물상자는 다섯 구간마다 3차선 또는 4차선의 넓은 도로 하나를 무작위로 골라 안쪽 차선에 배치한다. 기존 두 구간마다 한 개에서 빈도를 60% 낮췄다. 먹으면 하트 1개 회복, 8초 차량 감속, 피해 1회를 막는 보호막 중 하나가 즉시 적용된다. 하트가 가득 차거나 보호막이 이미 있으면 유효한 다른 효과를 뽑는다.
- 획득한 아이템은 캐릭터 머리 위에 큰 아이콘과 짧은 문구로 표시한다. 확대·반짝임과 함께 나타나 2.2초 동안 떠오른 뒤 사라지며 이동 중에도 캐릭터를 따라간다. 질문창에는 아이템을 표시하지 않고 남은 감속 시간·보호막은 상단의 작은 아이콘으로 유지한다. 일시정지 시 획득 연출도 멈추고 재시작·종료 시 정리한다.
- 선물은 한 번만 받을 수 있다. 감속 선물은 남은 시간에 더해지며 최대 20초까지 쌓인다. 구매 아이템과 인벤토리는 공통 플랫폼을 사용하고, 선물 효과는 현재 판에만 적용된다.
- 잔디 구간에는 바위와 나무를 합쳐 1~2개, 후반에는 최대 3개의 장애물을 배치한다. 두 개 이상인 구간은 두 종류를 함께 표시하고, 한 개뿐인 구간도 인접한 구간끼리 종류를 번갈아 섞는다. 전체 장애물 위치·개수는 기존 바위 배치와 같다. 두 종류 모두 사방에서 해당 칸의 이동만 막으며 하트나 보호막을 소모하지 않는다. 퀴즈 입구·횡단보도·도착 지점과 선물 자리는 비워 둔다. 단순한 입체 SVG를 조금씩 다른 크기로 표시하며, 그림의 세로 중심을 잔디 칸 중앙에 맞추고 그림 바닥에 맞춰 앞뒤 순서를 정한다. 바닥 영역이나 테두리는 없다.
- 피해를 입으면 마지막 안전지대로 돌아온다. 중복 피해를 막는 짧은 대기와 차량 재출발 보호 시간이 있다. 차량 보호 시간 중에도 오답 피해는 적용된다.
- 보호막은 오답·충돌 중 한 번을 막는다. 힌트는 풀이 단서, 지우기는 오답 길 하나 제거, 모래시계는 8초 차량 감속이다.
- 이동은 방향 버튼, 방향키/WASD, 탭·스와이프를 지원한다. 지난 두 구간까지 뒤로 이동할 수 있다. 오래 지난 구간은 정리해 긴 플레이에서도 메모리 사용과 재획득 방지를 유지한다.
- 그림은 기울기 없는 수평·수직 좌표계로 배치한다. 차량은 박스형 8종·양방향 16개 RGBA 시트를 사용하고, 차종 길이로 표시 너비와 충돌 범위를 맞춘다. 화면은 최대 3× 해상도로 그린다.
- 빠른 차량 뒤에는 짧은 속도선·옅은 잔상과 작은 차체 진동을 표시한다. 실제 속도에 따라 강도가 달라지고 차량 감속 중에는 약해지거나 사라진다. 주 차량 이미지는 선명하게 유지하고 회전·기울임을 적용하지 않는다. 동작 줄이기 설정에서는 부가 속도 연출을 생략한다.
- 선택한 캐릭터·의상·펫은 공통 ctx.character로 표시한다. 일시정지·탭 숨김·아이템 구매 중에는 차량·선물 애니메이션과 효과 시간이 멈춘다.
- 잔잔한 도로 배경음과 가까운 차량의 짧은 통과음을 재생한다. 차량 위치·방향·실제 속도에 따라 접근 시점, 좌우 이동, 재생 속도가 달라지고 감속 중에는 소리도 낮아진다. 여러 차가 지나가도 통과음을 연달아 겹치지 않도록 간격과 동시 재생 수를 제한한다. 퀴즈 입구에서 생각할 때나 정답·오답·선물 효과음이 나올 때 도로 소리를 25%로 낮춘다.
- 소리는 출발 이후 공통 소리 설정을 따르며 음소거·일시정지·아이템 구매·탭 숨김·종료 시 게임이 소유한 소스를 즉시 정리한다. 다시 켜도 지난 통과음을 몰아서 재생하지 않는다. 공유 AudioContext를 사용하고 다른 게임의 컨텍스트를 정지·종료하지 않는다. 통과음 파일 로딩에 실패해도 플레이와 합성 배경음은 계속된다.

규칙과 생성은 rules.js, 화면은 index.js / game.css, 차량 프레임은 vehicles.js, 도로 소리는 sound.js에 있다. tests/crossing.test.js가 무한 생성·경로·선물·난이도·충돌을, tests/crossing-audio.test.js가 소리의 근접 재생·볼륨·정리·지연 로딩을 검증한다.
