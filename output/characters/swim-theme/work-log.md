# 수영놀이 테마6종

내장 image_gen으로 남아/여아 긴소매 래시가드, 비치볼, 오리 튜브, 줄무늬 튜브, 수경을 생성했다. 기존 의상은 낮은 손 자세 및 몸 좌표, 기존 펫은 그림체, 기존 안경은 투명 렌즈 프레임 참고로 사용했다. 생성 원본과 실제 프롬프트는 generated/,prompts/에 보관했다.

의상과 소품은 투명256×256 WebP, 수경은384×192 WebP로 저장했다. 소품은 캐릭터 옆에 보이는 기존 동반 슬롯을 사용하며 펫·소품 분류와 소품 전용 사용/구매 문구를 추가했다. 비치볼110px, 오리 튜브130px, 줄무늬 튜브120px의 rig 크기로 설정했다. 기존 펫 크기는168px로 유지한다.

catalog.js의 2026-10-09b 신규 묶음으로 등록했다. 상세 테스트와 게임 화면 검증은 생략했다.
