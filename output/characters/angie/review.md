# Angie / 앤지

프로젝트 game-character-sheet 스킬과 내장 image_gen 사용. 제공 사진을 정체성, 수지 시트를 그림체 참고로 사용했다. 원본 사진은 공개 에셋에 복사하지 않았다. neutral 마스터의 실사 느낌을 2D 애니메이션 스타일로 수정하고, 같은 디자인으로 neutral/happy/angry/surprised/crying 시트를 생성했다. 실제 프롬프트는 prompts/에 보관했다.

생성 원본의 경계 접촉은 image_gen으로 수정했다. 이후 온전한 5개 셀 전체에 같은 축소·패딩으로 투명 여백을 확보했다. 각 얼굴을 따로 크롭하거나 재정렬하지 않았다. 제작 PNG는 output/character_expression_sheet.png (2560×960), 게임 WebP는 public/assets/characters/angie.webp (2560×512)다. 런타임 공통 크롭 밖 최대 alpha는1. cry는 게임 sad 슬롯에 연결한다.

피부 턱끝과 눈 중심을 수동으로 확인해 수지와 같은 눈–턱 렌더링 거리75.88px 및 턱끝 높이171.93px로 맞췄다. 기울어진 수지의 가로 치우침은 복사하지 않고 눈 midpoint를 몸 중심 x125에 맞췄다. landmarks.json과 face-fit.json에 계산을 보관했다. 안경, 모자, 리본, 핀 및 의상·팔의 레이어 순서를 실제 렌더러에서 확인했다.

구조 검사 통과. 놀람 표정의 실루엣 경고는 약간의 가로 위치/머리 실루엣 차이로 수동 검토했으며, 표정과 인물 인상을 유지해 채택했다. 픽셀 단위 완전 일치는 보장하지 않는다. 이름 번역, 프리셋 목록, RIGS에 추가했고 실제 캐릭터 선택 화면에서 앤지 선택이 서버에 저장됨을 확인했다. 의상 저장·조회·WebP 제공을 포함한 전체 게임 테스트95개 통과.

간격 보정의 반복 문제를 해결하기 위해 프로젝트 스킬에 `--pad-to-margin`을 추가했다. 클리핑/겹침은 여전히 실패하며, 온전한 시트의 간격만 공통 배율로 정리한다. 스킬 테스트13개 통과. 앤지 생성 원본으로 spacing-final-validation/qa-report.json에 실제 여백과 인접 간격을 검증했다. 폭 비정수5분할 경고와 놀람 실루엣 경고는 남으며 내용 검토를 완료했다.
