# 만두 (DimSum) 게임 연결

사용자가 캐릭터 추가를 요청해 `final/character_expression_sheet.png`를 새 프리셋 `dimsum`으로 연결했다. 한국어 이름은 만두, 영어 이름은 DimSum이다.

런타임: `public/assets/characters/dimsum.webp` (2560×512, lossless WebP). 5개 셀 전체에 같은 `[0,214,512,726]` 정사각형 크롭을 적용했다. 크롭 밖 최대 alpha는1이며 보이는 머리·귀·눈물은 잘리지 않았다. 순서는 neutral/happy/angry/surprised/sad이며 sad는 crying에 연결했다. 원본 사진은 공개 에셋에 포함하지 않았다.

최종 런타임 neutral의 양쪽 눈 중심과 피부 턱끝을 수동 확인해 `landmarks.json`에 기록했다. 수지의 눈–턱 거리75.8789px와 턱 높이·눈 midpoint 위치를 기준으로 만두의 얼굴 표시 크기를262.5×262.5px로 정했다. 눈 간격은 수지 대비1.0248배이며 가로/세로 공통 배율을 유지했다. 모자·리본·머리핀과 안경 위치를 실제 렌더러에서 확인했다.

검증: 서버·카탈로그·의상 관련 테스트27개 통과. 실제 캐릭터 선택 화면에서 만두 선택이 서버에 저장되고 새로고침 후 유지됨을 확인했다. 한국어 만두/영어 DimSum 이름, 5개 표정, 기본 티셔츠와 모자·안경·리본·해바라기 핀을 렌더링했다. `selection-review.png`, `render-review.png`에 확인 화면을 저장했다. 임시 검증 계정은 메모리 DB만 사용했고 서버와 브라우저를 정리했다.

생성 단계에서 보고한 가장자리 잔상 이력은 보존했다. 이번 연결에서는 그림을 다시 생성하거나 원본 alpha를 수정하지 않았다. 기존 캐릭터 에셋과 별도의 작업 중인 오디오 변경은 수정하지 않았다.
