# 전체 의상 손 자세 변경

내장 image_gen으로 기본 흰 티셔츠를 제외한13개 의상의 팔·손을 아래로 내린 자세로 수정했다. 기존 의상을 디자인 참고로, 수정된 기본 티셔츠를 자세 참고로 사용했다. 왼손은 아래/바깥으로 향하는 열린 손, 오른손은 허리 옆에서 연필을 드는 자세다.

기존 의상 크기와 투명 alpha를 유지하는 WebP로 변환해 public/assets/wearables/outfits/의 해당13개 파일에 적용했다. 원본은 input/, 생성 PNG는 generated/, 사용한 프롬프트는 prompts/, 최종 WebP는 prepared/에 보관했다. 요청대로 별도 게임 화면 검증이나 테스트는 실행하지 않았다. 캐릭터 이미지와 렌더링 순서는 변경하지 않았다.
