# 플라워 드레스 2종

퍼플 플라워 드레스는 기존 `purpleSunflowerDress` 항목의 그림과 이름을 갱신해 기존 보유 정보를 유지했다. 새 `orangeFloralDress`는 사진의 흰 바탕, 주황색 꽃무늬와 넓은 주황색 랩 허리띠를 게임 스타일로 옮긴 드레스이다. 둘 다 옷 슬롯,25 Sparkles,2026-10-12 신규 배치로 등록했다. 이전 배치의 퍼플 ID를 제거해 신규 날짜가 덮어써지지 않도록 했다.

생성 도구: 내장 image_gen. 실제 프롬프트는 `../purple-flower-dress/prompt.md`, `../purple-flower-dress/margin-prompt.md`, `../orange-floral-dress/prompt.md`에 보관했다. 원본 사진은 로컬 제작 입력으로만 보관한다. 팔·손·연필을 포함한 기존 게임 의상 구도와 투명 배경을 유지했다. Sharp는256×256 크기와lossless WebP 형식 변환에만 사용했다.

QA: 두 에셋 모두256×256, 실제 alpha0–255. 퍼플 보이는 영역 `[6,83,249,215]`, 오렌지 `[6,76,254,217]`이며 캔버스 경계에서 잘리지 않는다. 실제 로컬 상점에서 두 드레스가 맨 위에 NEW/25 표시로 나타나는 것을 확인했고 각각 눌러 입어보기 동작을 확인했다. 실제 `createCharacter` 렌더러로 만두의 퍼플 드레스+퍼플 플라워 리본, 오렌지 드레스를 확인했다. 확인 화면은 `render-review.png`이다. 구매·착용 확정은 사용자 계정에서 실행하지 않았다.
